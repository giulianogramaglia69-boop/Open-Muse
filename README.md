# Open-Muse

Open-Muse — open-source cross-platform desktop client for Muse, Meta's personal AI agent (Linux, Windows, macOS).

## Vision

Open-Muse is an open-source Tauri-based desktop client that wraps the Muse web app (muse.ai) with native features — system tray, global shortcut, and notifications — built for Linux, Windows, and macOS.
